# Freestyle

Plugins for Revenge Next.

| Plugin | ID |
| --- | --- |
| Better Animations | `yumistra.better-animations` |
| Message Actions | `yumistra.message-actions` |
| Overlay Background | `yumistra.overlay-background` |
| Plugin Backup | `yumistra.plugin-backup` |
| Server Folders | `yumistra.server-folders` |
| Silent Leave | `yumistra.silent-leave` |
| Toast Fix | `yumistra.toast-fix` |

## Install

Add this repository in Revenge → Plugins:

```
https://yumistra.github.io/Freestyle
```

## Build

```sh
npm install
npm run build
npm run package -- --base-url https://yumistra.github.io/Freestyle
```

Pushing to `main` builds and deploys to GitHub Pages.
